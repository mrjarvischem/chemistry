Uncertainty in measurements

AQA GCSE 4.3.1.4 / Trilogy 5.3.1.4

Repeat the experiment

Key points

  • Whenever a measurement is made there is always some uncertainty about the result.
  • Random errors make each reading slightly too high or too low, so repeats are not identical.
  • Repeating and calculating a mean reduces the effect of random errors.
  • A result is written as mean ± uncertainty, for example 48 ± 2 cm³. The true value is likely to be between 46 and 50 cm³.

Method

  • An anomalous result does not fit the pattern of the other results.
  • Leave out any anomalous result.
  • Mean = sum of the results you are keeping ÷ how many results you are keeping.

Method

  • Calculate the mean (leave out any anomalous result).
  • Range = highest value − lowest value.
  • Uncertainty = ± range ÷ 2 (half the range).
  • Write the result as mean ± uncertainty, with the unit.

Key points

  • Precise results are close together: a small range, so a small uncertainty.
  • Accurate results are close to the true value.
  • Results can be precise but not accurate. If every result is too high (or too low) by a similar amount there is a systematic error, for example a balance that was not set to zero.
  • To reduce uncertainty: repeat and calculate a mean, and use apparatus with smaller scale divisions (a burette instead of a measuring cylinder).
