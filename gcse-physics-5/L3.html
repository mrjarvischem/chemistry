Resultant force

A number of forces acting on an object can be replaced by a single force with the same effect — the resultant force. Change the two forces on the crate.

Push to the right: N
Forces in the same direction add. Forces in opposite directions subtract. If the resultant is zero, the forces are balanced.

Free body diagrams

A free body diagram shows the object as a dot or box with an arrow for every force acting on it — size shown by length, direction by the arrow.

A plane flying at a steady speed and height:

  • lift balances weight
  • thrust balances drag
  • resultant force = 0

Forces at an angle Higher tier

When forces aren’t in a line, find the resultant with a scale drawing: put the arrows tip to tail. The resultant goes from the start of the first to the end of the last.

Force north: N
Resolving works the other way: a single force at an angle can be split into two components at right angles (e.g. horizontal and vertical). If the arrows for all the forces on an object make a closed triangle, the object is in equilibrium (resultant = 0).

Exam practice

Lesson summary

  • Resultant force: the single force with the same effect as all the forces acting.
  • Same direction: add. Opposite directions: subtract. Zero resultant: balanced.
  • Free body diagram: an arrow for every force on the object.
  • HT: tip-to-tail scale drawings; resolve forces into perpendicular components; closed triangle → equilibrium.
