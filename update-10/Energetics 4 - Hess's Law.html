Hess's Law

Finding enthalpy changes you cannot measure, by adding equations or drawing a cycle with formation or combustion data.

Why do we need Hess's law?

Many enthalpy changes cannot be measured by experiment. Carbon and hydrogen will not react cleanly to make only methane, so ΔfH of methane cannot be found with a calorimeter:

C(s) + 2H₂(g) → CH₄(g)    ΔH = ?

But we can burn carbon, hydrogen and methane and measure those enthalpy changes. Hess's law lets us use them to get the one we want.

Hess's law

The enthalpy change for a reaction is independent of the route taken, as long as the start and end are the same.

It works because energy is conserved. Like climbing a hill: your height gain is the same whichever path you take.

Take both routes

Enthalpy change so far: 0 kJ

Route 2 goes down to the combustion products (−966 kJ), then back up to methane (+890 kJ, the reverse of burning methane).

CHECK 1

State Hess's law.

The enthalpy change for a reaction is independent of the route taken (it depends only on the initial and final states).

CHECK 2

Suggest why the enthalpy change for C(s) + ½O₂(g) → CO(g) cannot be measured directly.

Some of the carbon always burns further to CO₂, so you cannot make only CO.

Method 1: add the equations

Treat the data equations like building blocks. Scale them and flip them until they add up to the target equation. Whatever you do to an equation, do the same to its ΔH.

Multiply an equation

Multiply ΔH by the same number.

Reverse an equation

Change the sign of ΔH.

Target: C(s) + 2H₂(g) → CH₄(g)

The data: three enthalpies of combustion.

EquationΔH / kJ mol⁻¹
C(s) + O₂(g) → CO₂(g)−394
H₂(g) + ½O₂(g) → H₂O(l)−286
CH₄(g) + 2O₂(g) → CO₂(g) + 2H₂O(l)−890

Scale and reverse. The target needs 2H₂ on the left, so double the hydrogen equation. It needs CH₄ on the right, so reverse the methane equation.

EquationΔH / kJ mol⁻¹
C(s) + O₂(g) → CO₂(g)−394unchanged
2H₂(g) + O₂(g) → 2H₂O(l)−572× 2
CO₂(g) + 2H₂O(l) → CH₄(g) + 2O₂(g)+890reversed

Add and cancel. Anything that appears on both sides cancels: CO₂, 2H₂O and 2O₂.

EquationΔH / kJ mol⁻¹
C(s) + O₂(g) → CO₂(g)−394
2H₂(g) + O₂(g) → 2H₂O(l)−572
CO₂(g) + 2H₂O(l) → CH₄(g) + 2O₂(g)+890
C(s) + 2H₂(g) → CH₄(g)−76

ΔH = −394 + (−572) + 890 = −76 kJ mol⁻¹

CHECK 3

Use these to find ΔH for C(s) + ½O₂(g) → CO(g).
C(s) + O₂(g) → CO₂(g)   ΔH = −394 kJ mol⁻¹
CO(g) + ½O₂(g) → CO₂(g)   ΔH = −283 kJ mol⁻¹

Keep the first equation. Reverse the second: CO₂(g) → CO(g) + ½O₂(g), ΔH = +283.
Add: CO₂ cancels and ½O₂ cancels from each side, leaving C(s) + ½O₂(g) → CO(g).
ΔH = −394 + 283 = −111 kJ mol⁻¹

CHECK 4

Use these to find ΔH for 2NO(g) + O₂(g) → 2NO₂(g).
½N₂(g) + ½O₂(g) → NO(g)   ΔH = +90 kJ mol⁻¹
½N₂(g) + O₂(g) → NO₂(g)   ΔH = +33 kJ mol⁻¹

Reverse and double the first: 2NO(g) → N₂(g) + O₂(g), ΔH = −180.
Double the second: N₂(g) + 2O₂(g) → 2NO₂(g), ΔH = +66.
Add: N₂ cancels and one O₂ cancels. ΔH = −180 + 66 = −114 kJ mol⁻¹

Method 2: a cycle with combustion data

The same calculation can be drawn as a triangle. Both the reactants and the products burn to give the same combustion products, so those go at the bottom and the arrows point down.

1
Write the target equation across the top.
2
Put the combustion products at the bottom. Draw an arrow down from each side: each arrow is "burn everything in this box".
3
Label each arrow with the total ΔcH for that box. Left: −394 + 2(−286) = −966. Right: −890.
4
Go from reactants to products the long way round. Travelling with an arrow, keep its sign. Travelling against an arrow, change its sign.
5
Add up the route: ΔH = −966 + 890 = −76 kJ mol⁻¹. The same answer as adding the equations.

Shortcut for combustion data

ΔH = ΣΔcH(reactants) − ΣΔcH(products)

O₂ does not burn, so its ΔcH is zero. Multiply each ΔcH by the number in front of that substance.

CHECK 5

Calculate ΔfH of ethene: 2C(s) + 2H₂(g) → C₂H₄(g).
ΔcH / kJ mol⁻¹: C(s) −394, H₂(g) −286, C₂H₄(g) −1411

Reactants: 2(−394) + 2(−286) = −1360   Products: −1411
ΔH = −1360 − (−1411) = +51 kJ mol⁻¹

CHECK 6

Calculate ΔfH of propane: 3C(s) + 4H₂(g) → C₃H₈(g).
ΔcH / kJ mol⁻¹: C(s) −394, H₂(g) −286, C₃H₈(g) −2219

Reactants: 3(−394) + 4(−286) = −2326   Products: −2219
ΔH = −2326 − (−2219) = −107 kJ mol⁻¹

CHECK 7

Calculate ΔH for C₂H₄(g) + H₂(g) → C₂H₆(g).
ΔcH / kJ mol⁻¹: C₂H₄(g) −1411, H₂(g) −286, C₂H₆(g) −1560

Reactants: −1411 + (−286) = −1697   Products: −1560
ΔH = −1697 − (−1560) = −137 kJ mol⁻¹

A cycle with formation data

Every compound can be made from its elements, so with ΔfH data the elements go at the bottom and the arrows point up to the reactants and to the products.

1
Target equation across the top: iron(III) oxide reduced by carbon monoxide.
2
Elements at the bottom. Draw an arrow up to each side: each arrow is "make everything in this box from its elements".
3
Label each arrow. Left: −822 + 3(−111) = −1155. Right: 3(−394) = −1182. Fe is an element, so its ΔfH is 0.
4
Reactants to products the long way: against the left arrow (change the sign), then with the right arrow.
5
ΔH = +1155 − 1182 = −27 kJ mol⁻¹

Shortcut for formation data

ΔH = ΣΔfH(products) − ΣΔfH(reactants)

Any element in its standard state has ΔfH = 0. Notice the shortcut is the opposite way round to the combustion one, because the arrows point the other way.

CHECK 8

Calculate ΔH for CaCO₃(s) → CaO(s) + CO₂(g).
ΔfH / kJ mol⁻¹: CaCO₃ −1207, CaO −635, CO₂ −394

Products: −635 + (−394) = −1029   Reactants: −1207
ΔH = −1029 − (−1207) = +178 kJ mol⁻¹

CHECK 9

Calculate ΔH for 2Al(s) + Fe₂O₃(s) → Al₂O₃(s) + 2Fe(s).
ΔfH / kJ mol⁻¹: Al₂O₃ −1676, Fe₂O₃ −822

Al and Fe are elements: ΔfH = 0.
ΔH = −1676 − (−822) = −854 kJ mol⁻¹

CHECK 10

Calculate ΔcH of ethanol: C₂H₅OH(l) + 3O₂(g) → 2CO₂(g) + 3H₂O(l).
ΔfH / kJ mol⁻¹: C₂H₅OH(l) −277, CO₂(g) −394, H₂O(l) −286

Products: 2(−394) + 3(−286) = −1646   Reactants: −277 (O₂ is an element, 0)
ΔH = −1646 − (−277) = −1369 kJ mol⁻¹

Stretch: finding a missing value

Fe₂O₃(s) + 3CO(g) → 2Fe(s) + 3CO₂(g)   ΔH = −27 kJ mol⁻¹. Given ΔfH: Fe₂O₃ −822 and CO −111, find ΔfH of CO₂.

1
Write the shortcut with x for the unknown: −27 = 3x − [−822 + 3(−111)]
2
Work out the bracket: −27 = 3x − (−1155) = 3x + 1155
3
Rearrange: 3x = −27 − 1155 = −1182
4

x = −394 kJ mol⁻¹

CHECK 11

N₂H₄(l) + O₂(g) → N₂(g) + 2H₂O(l)   ΔH = −622 kJ mol⁻¹. ΔfH of H₂O(l) = −286 kJ mol⁻¹. Calculate ΔfH of hydrazine, N₂H₄(l).

−622 = 2(−286) − x   (N₂ and O₂ are elements, 0)
−622 = −572 − x, so x = −572 + 622 = +50 kJ mol⁻¹
