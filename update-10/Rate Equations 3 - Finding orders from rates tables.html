Rate Equations 3 – Finding Orders from Rates Tables

AQA A-level Chemistry · Kinetics walkthrough

1. Reading a rates table

A rates table shows several experiments done at the same temperature, with different starting concentrations. The initial rate is measured each time.

  1. Find two experiments where only one concentration changes. Everything else stays the same.
  2. Work out the factor that concentration changed by (e.g. × 2).
  3. Work out the factor the rate changed by.
  4. Match them: rate factor = (concentration factor)order.
  5. Repeat for each reactant, then write the rate equation.

Watch out:
• Sometimes the "rate" column is a relative rate. Use it exactly the same way.
• Sometimes you get a time instead of a rate (a clock reaction). Rate ∝ 1/t, so if the time halves, the rate doubles.
• Experimental data is rarely perfect. A factor of 1.98 means ×2.

2. When two concentrations change at once

Exam tables often have no clean pair for one of the reactants. Then:

  1. Find the order of a reactant you can get from a clean pair.
  2. For the messy pair, work out how much the rate would change because of the reactant you already know.
  3. Compare that with the actual change in rate. Whatever is left over must be caused by the other reactant.

  1. Initial rates (from Walkthrough 1): exp 2 = (2.00 − 1.84) × 10⁻² ÷ 5.0 = 3.2 × 10⁻⁴. Exp 3 = (0.50 − 0.34) × 10⁻² ÷ 5.0 = 3.2 × 10⁻⁴
  2. Order of P, exp 1 → 2: only [P] changes, ×2. Rate ×2 → first order in P
  3. Exp 1 → 3: both change. [P] ×½ and [Q] ×2. The rate actually changes ×2.
  4. Effect of P alone: first order, so [P] ×½ makes the rate ×½.
  5. Effect of Q must be: actual ÷ P effect = 2 ÷ ½ = ×4. [Q] ×2 gave rate ×4, so second order in Q
  6. rate = k[P][Q]²

3. Calculating k and completing tables

Once you have the rate equation, you can:

  • Calculate k using any one experiment. k should be the same for every row, because the temperature is the same.
  • Fill in missing values. Either use the factor method between rows, or put k back into the rate equation.

  1. k from exp 1: k = 2.4 × 10⁻² ÷ (0.10 × 0.20 × 0.30²) = 2.4 × 10⁻² ÷ 1.8 × 10⁻³ = 13 mol⁻³ dm⁹ s⁻¹ (2 s.f., to match the data). Overall order 4.
  2. Exp 2: rate ×1.5 with only [BrO₃⁻] changed (first order), so [BrO₃⁻] = 0.10 × 1.5 = 0.15
  3. Exp 3: rate = 13.3 × 0.20 × 0.40 × 0.50² = 0.27 mol dm⁻³ s⁻¹ (0.26 if you use k = 13)
  4. Exp 4: [H⁺]² = 2.7 × 10⁻² ÷ (13.3 × 0.10 × 0.10) = 0.2025, so [H⁺] = √0.2025 = 0.45
When you rearrange for a second order concentration, remember to take the square root at the end.
