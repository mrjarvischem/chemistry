1. Start with ammonia

An amine is ammonia, NH₃, with one or more H atoms replaced by alkyl or aryl groups (R).

NH₃ → RNH₂ → R₂NH → R₃N → R₄N+

Every amine (except the quaternary ion) still has the lone pair on nitrogen. That one lone pair explains almost all of amine chemistry.

3. Naming amines

  • Primary: alkyl name + amine – ethylamine, propylamine. (IUPAC style: ethanamine, propan-1-amine.) If the NH₂ isn't on the end: propan-2-amine.
  • Secondary / tertiary: list the alkyl groups alphabetically, with di/tri for repeats – diethylamine, ethylmethylamine, trimethylamine. (IUPAC style uses N-: N-methylethanamine.)
  • Quaternary ammonium salts: alkyl groups + ammonium + anion – tetramethylammonium bromide.
  • Aromatic: C₆H₅NH₂ is phenylamine.
  • When another group has priority, NH₂ is called amino: H₂NCH₂CH₂OH is 2-aminoethanol.

4. One lone pair, every reaction

The lone pair on N can be used in two ways:

  • to accept an H+ → the amine is a base (walkthrough 3)
  • to attack a δ+ carbon → the amine is a nucleophile (walkthrough 4)
